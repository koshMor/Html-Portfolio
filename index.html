            Formula Cheat Sheet

            • Slope-intercept form: y = mx + b
            • Point-slope form: y - y₁ = m(x - x₁)
            • Distributive property: a(b + c) = ab + ac
            • Zero product property: if ab = 0, then a = 0 or b = 0
            • Average rate of change = (change in y) / (change in x)
